## My Favorite Series: *Avatar: The Last Airbender*

**Avatar: The Last Airbender** is an animated fantasy series about a world split into four nations: *Water*, *Earth*, *Fire* and *Air*.

> "Hope is something you give yourself. That is the meaning of inner strength." – Iroh

### Quick Facts

| Detail | Info |
| --- | --- |
| Genre | Animation, Adventure, Fantasy |
| Seasons | 3 (called "Books") |
| Episodes | 61 |
| Main Character | Aang |

### Main Characters

1. Aang – the Avatar and last Airbender
2. Katara – a Waterbender and healer
3. Sokka – the strategist of the group
4. Zuko – the exiled Fire Nation prince

### Why I Like It

- Great character development
- Strong story and world-building
- Funny and emotional moments
- Lessons about *friendship*, **responsibility** and ~~giving up~~ perseverance
